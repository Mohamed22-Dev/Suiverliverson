## 📱 About the Project

**Liverson** is a mobile application developed to simplify the work of delivery drivers. It provides an organized platform where drivers can manage their profiles, receive delivery orders, track their locations, and monitor their performance.

The application offers a clean and user-friendly interface with multilingual support.

## ✨ Features

- **Driver Authentication:** Login and account registration.
- **Profile Management:** Manage personal information and vehicle details.
- **Delivery Requests:** Receive, accept, or reject delivery requests.
- **Real-Time Notifications:** Stay informed about new orders and delivery updates.
- **Dashboard:** View daily earnings, completed trips, and driver ratings.
- **Statistics:** Track weekly earnings and customer reviews.
- **Google Maps:** Display driver location and delivery routes.
- **QR Code:** Generate and display a personal driver QR code.
- **Order History:** Access previous delivery information.
- **Settings:** Update account information and notification preferences.
- **Multilingual Support:** English, French, and Arabic.

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/Mohamed22-Dev/Suiverliverson.git
```

2. Open the project using Android Studio.

3. Wait for Gradle synchronization to finish.

4. Configure the required API keys if necessary.

5. Connect an Android device or start an emulator.

6. Run the application.
